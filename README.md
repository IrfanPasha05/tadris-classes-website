# Tadris Classes Website

A responsive, single-page admissions and enquiry website for Tadris Classes.

## Included
- Responsive navigation for desktop and mobile
- Home, About, Courses, Online/Offline learning, FAQs and Contact sections
- Enquiry form that prepares a WhatsApp message to **+91 99012 35919**
- Click-to-call and floating WhatsApp contact
- Accessible labels, semantic sections and mobile-friendly layout

## Run locally
No build step is required. Open `index.html` in a browser, or serve the folder with a local static server.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Customise
- Edit colours and layout in `style.css`.
- Edit sections and text in `index.html`.
- Update the WhatsApp number in both `index.html` and `script.js` if it changes.
- The two classroom photos currently load from Unsplash and require an internet connection.

## Branding assets
The supplied Tadris logo and promotional poster have not been committed as image files in this upload. Add them under `images/` when available, then update the relevant image references in `index.html`. The wordmark in the header is a text-based temporary treatment.

## Accuracy note
Course categories and contact details follow the supplied Tadris Classes information. Fees, schedules, location, faculty credentials and testimonials are intentionally not invented; contact the centre for current details.
